양보고서 양식 맞춤
변환 엔진 준비 중…

회사에서 쓰던 보고서를 양식으로 올리고, 바꿀 문서를 올리면 그 양식에 맞춘 한글 파일(.hwpx)을 만들어 드립니다.

🔒 모든 처리는 이 컴퓨터의 브라우저 안에서 이루어집니다. 올린 파일은 어디로도 전송되지 않습니다.

양식 저장소

저장해 둔 양식을 누르면 1단계에 바로 씁니다.

    아직 저장한 양식이 없습니다. 1단계에서 양식을 올린 뒤 + 양식 저장을 누르면 여기에 보관되어 다음에도 바로 쓸 수 있습니다.

    🔒 양식은 이 컴퓨터의 이 브라우저 안에만 보관됩니다. 다른 컴퓨터·브라우저에서는 보이지 않습니다.

    1

    어떤 양식으로 바꿔드릴까요?

    양식으로 쓸 보고서(.hwpx)를 여기에 끌어다 놓으세요

    또는

    표지·차례·본문이 들어 있는 완성된 보고서일수록 양식을 정확히 알아냅니다. .hwp는 한글에서 HWPX로 저장해 주세요.
    양식이 앞표지·목차·본문·표 그림 양식처럼 여러 파일로 나뉘어 있으면 한꺼번에 올리세요. 부분마다 알맞은 파일을 골라 하나의 양식으로 씁니다.

    어떤 파일을 양식으로 쓸 수 있나요?

    꼭 필요한 것 — 없으면 양식으로 받지 않습니다

    • 한글 .hwpx 파일 (.hwp는 한글에서 [파일] → [다른 이름으로 저장] → 파일 형식 'HWPX')
    • 암호나 배포용 잠금이 걸려 있지 않을 것
    • 표 밖에 줄글로 쓴 본문 문단이 한 개 이상 있을 것 (신청서·공문처럼 칸을 채우는 서식은 쓸 수 없습니다)

    있으면 그 모양으로 맞추는 것 — 없으면 아래처럼 처리하고 미리 알려 드립니다

    • 제목 줄을 단계마다 한 줄씩 — '1. 제목', '가. 제목', '□ 제목'처럼 번호·기호를 직접 쳐도, 자동 번호여도, 번호 없이 굵은 글씨여도 됩니다. 없으면: 문서의 제목을 어떻게 둘지 변환 전에 여쭤봅니다.
    • 표와 표 제목, 그림(또는 그림 틀)과 그림 제목 없으면: 문서의 표·그림을 원래 모양 그대로 둡니다.
    • 머리말·꼬리말·쪽 번호, '제1장 …' 같은 장 제목 없으면: 없이 만들거나 변환 전에 여쭤봅니다.

    없어도 되는 것

    • 표지와 차례 — 없으면 원하실 때 간단한 모양으로 만들어 드립니다.

    양식을 올리면 위 항목을 바로 검사해 보여 드립니다. 제목·본문 줄을 잘못 알아봤다면 그 자리에서 고칠 수 있습니다.

    2

    어떤 문서를 이 양식에 맞게 바꿔드릴까요?

    바꿀 문서(.docx 또는 .hwpx)를 여기에 끌어다 놓으세요

    또는

    글자는 그대로 두고 서식만 양식에 맞춥니다.

    3

    완성된 파일

    한글(HWPX) 문서 서식을 바꾸는 도구 · 결과는 꼭 한글에서 열어 확인해 주세요. · 개인정보 처리방침

    파일 가져오기

    어떻게 만들어 드릴까요?

    원하시는 결과를 정확히 만들기 위해 몇 가지만 여쭤볼게요.

    1-1. 제목을 만들어 드릴까요? (제목 페이지)

    1-2. 제목을 뭐라고 작성할까요?

    2. 목록을 만들어 드릴까요? (차례 페이지)
    3. 페이지 번호를 어떻게 작성해드릴까요?
    4-1. 머리말을 만들어 드릴까요?

    4-2. 머리말을 뭐라고 작성할까요?

    5. 큰 표가 쪽을 넘어가면 어떻게 나눌까요?

    어느 쪽이든 표가 쪽 아래로 넘치지 않게 나눕니다.

    제목·본문 줄 고치기

    양식에서 찾은 줄입니다(같은 모양은 한 줄로 묶었습니다). 줄마다 무엇으로 쓸지 골라 주세요. 제목은 1단계부터 차례로 쓰이고, 고르지 않은 줄은 쓰지 않습니다.
