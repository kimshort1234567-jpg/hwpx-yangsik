양보고서 양식 맞춤

개인정보 처리방침

시행일: 2026년 11월 4일

「보고서 양식 맞춤」(이하 '이 도구')은 회사 보고서 양식에 맞춰 한글(.hwpx) 문서를 만들어 주는 웹 도구입니다. 이 도구는 개인정보를 수집하거나 저장하지 않습니다.

1. 올린 파일

  • 양식과 문서 파일은 사용자의 브라우저 안에서만 처리됩니다. 변환 프로그램이 브라우저 안에서 실행되며, 파일 내용을 어떤 서버로도 보내지 않습니다.
  • 만든 결과 파일은 사용자의 다운로드 폴더에 저장됩니다. 페이지를 닫으면 브라우저 메모리의 파일 내용도 사라집니다.
  • [+ 양식 저장]을 누른 양식만 다음에 다시 쓸 수 있도록 이 브라우저의 저장 공간(IndexedDB)에 보관합니다. 이 저장 공간은 사용자의 컴퓨터 안에 있으며, 보관한 파일을 어떤 서버로도 보내지 않습니다. 양식 저장소에서 지우거나 브라우저의 사이트 데이터를 지우면 사라집니다.

2. Google 드라이브에서 가져오기

  • 사용자가 [Google 드라이브에서 가져오기]를 누르면 Google 로그인과 권한 동의를 거칩니다.
  • 요청하는 권한은 drive.file 하나입니다. 이 권한으로는 사용자가 파일 고르기 창에서 직접 고른 파일만 읽을 수 있으며, 드라이브의 다른 파일은 볼 수 없습니다.
  • 고른 파일은 Google 드라이브에서 사용자의 브라우저로 바로 내려받아 1번과 같이 처리합니다. 드라이브의 파일을 바꾸거나 지우거나 새로 만들지 않습니다.
  • Google이 발급한 접근 토큰은 브라우저 메모리에만 잠시 두며, 저장하거나 다른 곳으로 보내지 않습니다. 페이지를 닫으면 사라집니다.
  • Google 사용자 데이터를 광고, 판매, 분석, 인공지능 학습 등 다른 목적에 쓰지 않으며 제3자와 공유하지 않습니다.
  • 권한은 언제든지 Google 계정의 서드 파티 연결에서 철회할 수 있습니다.

3. 외부에서 불러오는 것

  • 변환 프로그램(Pyodide)은 jsDelivr(cdn.jsdelivr.net)에서 불러옵니다.
  • Google 드라이브 기능을 쓸 때에만 Google의 로그인·파일 고르기 도구(accounts.google.com, apis.google.com)를 불러옵니다.
  • 이 과정에서 각 업체가 일반적인 접속 기록(IP 주소 등)을 남길 수 있으며, 이는 각 업체의 방침을 따릅니다. 이 도구는 쿠키·방문 분석·광고 도구를 쓰지 않습니다.
