# 보고서 양식 맞춤 (hwpx-yangsik)

회사에서 쓰던 보고서를 **양식**으로 올리고, 바꿀 **문서**(워드 .docx 또는 한글 .hwpx)를 올리면
그 양식의 서식으로 바꾼 한글 파일(.hwpx)을 만들어 주는 웹 도구입니다.

**바로 쓰기: https://kimshort1234567-jpg.github.io/hwpx-yangsik/**

- 설치 없이 브라우저에서 바로 씁니다.
- **파일은 밖으로 나가지 않습니다.** 변환은 브라우저 안의 파이썬(Pyodide, WebAssembly)이 처리하고 서버로 아무것도 보내지 않습니다.
- 글자는 그대로 두고 서식만 바꿉니다. 바뀌는 글자는 직접 친 번호·기호(양식의 자동 번호로 바꿈)처럼 '번호'에 해당하는 것뿐이며, 결과 화면에 몇 곳인지 알려 줍니다.

## 쓰는 방법

1. **어떤 양식으로 바꿔드릴까요?** — 양식으로 쓸 보고서(.hwpx)를 끌어다 놓거나 [파일 가져오기]로 고릅니다.
   표지·차례·장 제목·번호 단계·본문·표·그림·머리말·쪽 번호를 자동으로 찾아 보여 줍니다.
2. **어떤 문서를 이 양식에 맞게 바꿔드릴까요?** — 바꿀 문서(.docx 또는 .hwpx)를 올립니다.
3. 설정 창에서 답합니다.
   - 1-1 제목(표지)을 만들까요? → 1-2 직접 작성 / 본문 내용 분석 후 자동 생성
   - 2 목록(차례)을 만들까요?
   - 3 페이지 번호: 제목부터 1 / 본문부터 1 / 필요 없음 / 별도 지정(본문 첫 쪽 번호)
   - 4-1 머리말을 만들까요? → 4-2 직접 작성 / 본문 내용 분석 후 자동 생성
   - 5 큰 표가 쪽을 넘어가면 어떻게 나눌까요? → 쪽 경계에서 나눔 / 셀 단위로 나눔
     (한 쪽을 넘는 표가 있을 때만 묻습니다. 어느 쪽이든 표가 쪽 아래로 넘치지 않고, 표 머리행은 다음 쪽에도 나옵니다.
     한 쪽 안에 드는 표는 양식대로 두어 쪽 끝에 걸리면 통째로 다음 쪽으로 넘어갑니다.)
4. [변환하기]를 누르면 결과 파일이 **다운로드 폴더**에 저장됩니다. 같은 양식으로 다른 문서도 이어서 바꿀 수 있습니다.

내 컴퓨터에서 쓰려면 이 저장소를 내려받아 `web/index.html`을 브라우저(크롬·엣지·웨일)로 열면 됩니다.
처음 열 때 변환 엔진(약 10 MB)을 인터넷에서 한 번 받아 옵니다.

## 받는 파일

| | 양식 | 바꿀 문서 |
|---|---|---|
| 한글 .hwpx | ✅ | ✅ (구역이 여럿이어도 됨) |
| 워드 .docx | — | ✅ |
| 한글 .hwp | 한글에서 HWPX로 저장 후 | 한글에서 HWPX로 저장 후 |

## 아직 안 되는 것 (다음 판)

- **차례의 쪽 번호**: 쪽 나눔은 한글 프로그램이 계산하므로, 지금은 차례 항목만 만들고 쪽 번호는 비워 둡니다.
- Google 드라이브에서 가져오기(설정 필요 — 준비 중).
- 양식 보관함: 자주 쓰는 양식을 저장해 두고 고르기.
- .hwp 파일 직접 읽기, 워드(.docx) 양식.
- 문단 안 일부만 굵게·밑줄(원고 색 글자는 살립니다).

## 어떻게 동작하나

```
web/            화면(index.html, app.js, style.css)과 엔진 묶음(engine_bundle.js — tools/build_web.py가 만듦)
engine/         변환 엔진(파이썬, lxml) — 브라우저 안 Pyodide와 일반 파이썬에서 똑같이 돈다
  template_profile.py  양식 자동 분석: 쪽을 나눠 표지·차례·본문을 찾고 역할별 기준 문단을 고른다
  format_transfer.py   서식 옮기기: 원고 문단마다 역할을 정하고 양식 문단을 복사해 원고 글자를 채운다
  table_fit.py         표가 쪽을 넘지 않게: 셀 글자로 표 높이를 어림(한글이 저장한 줄 배치 정보로 맞춘 값)하고,
                       한 쪽을 넘는 표만 '글자처럼 취급'을 끄고 쪽 경계에서 나뉘게 한다
  docx_hwpx.py         워드 문서 → 한글(HWPX) 원고
  service.py           양식 분석 → 문서 살펴보기(규칙으로 못 정한 문단 자동 판단) → 설문 답으로 변환
tests/          시험 도구(아래)
tools/          build_web.py
```

HWPX는 ZIP 안의 XML이라 한글 프로그램 없이 만들 수 있습니다. 규칙: XML은 lxml로만 고치고, 내용을 바꾼 문단의 줄 배치 정보(linesegarray)는 지우며,
압축할 때 `mimetype`을 첫 항목·비압축으로 넣습니다. 결과마다 패키지·글자 보존·서식 일치·쪽을 넘을 수 있는 표를 자동 검사합니다(검증보고).
한글이 있는 PC에서는 PDF로도 확인합니다(본문 영역 아래로 넘친 글자가 없는지 등).

## 개발

```
python tools/build_web.py                                   # 엔진을 고친 뒤 웹 묶음 다시 만들기
python -X utf8 engine/service.py 양식.hwpx 문서.docx 작업폴더 '{"표지":{"만들기":true},"차례":{"만들기":true},"쪽번호":{"방식":"본문부터"},"머리말":{"만들기":true}}'
node tests/pyodide_node_test.mjs <node_modules/pyodide> 양식.hwpx 문서.hwpx 결과폴더   # 브라우저와 같은 Pyodide 환경
python -X utf8 tests/e2e_web.py 양식.hwpx 문서.hwpx 결과폴더 [--file]                # 실제 브라우저(Edge)로 화면 끝까지
python -X utf8 tests/try_template.py 양식.hwpx 원고설정.json 작업폴더 [--pdf]          # 한글이 있는 PC: PDF까지 확인
```

필요한 것: 파이썬 3.10+, lxml (웹에서는 Pyodide 0.29.5가 대신함).
