# 보고서 양식 맞춤 (hwpx-yangsik)

회사에서 쓰던 보고서를 **양식**으로 올리고, 바꿀 **문서**(워드 .docx 또는 한글 .hwpx)를 올리면
그 양식의 서식으로 바꾼 한글 파일(.hwpx)을 만들어 주는 웹 도구입니다.

**바로 쓰기: https://kimshort1234567-jpg.github.io/hwpx-yangsik/**

- 설치 없이 브라우저에서 바로 씁니다.
- **파일은 밖으로 나가지 않습니다.** 변환은 브라우저 안의 파이썬(Pyodide, WebAssembly)이 처리하고 서버로 아무것도 보내지 않습니다.
- 글자는 그대로 두고 서식만 바꿉니다. 바뀌는 글자는 직접 친 번호·기호(양식의 자동 번호로 바꿈)처럼 '번호'에 해당하는 것뿐이며, 결과 화면에 몇 곳인지 알려 줍니다.
- 결과의 모든 문단 모양은 줄 나눔 기준이 **한글 단위 '글자'·영어 단위 '글자'**입니다. 긴 경로·주소가 통째로 다음 줄로 넘어가
  양쪽 정렬한 윗줄의 낱말 사이가 크게 벌어지는 일이 없습니다(대신 줄 끝에서 낱말이 나뉠 수 있습니다).
- **양식 저장소**: 1단계에서 올린 양식을 [+ 양식 저장]으로 보관해 두면 다음에는 **양식 저장소**에서 눌러 바로 씁니다.
  이 브라우저 안에만 보관됩니다(아래 '양식 저장소' 참고).

## 쓰는 방법

1. **어떤 양식으로 바꿔드릴까요?** — 양식으로 쓸 보고서(.hwpx)를 끌어다 놓거나 [파일 가져오기]로 고릅니다
   (기기에서 업로드 또는 Google 드라이브에서 가져오기).
   표지·차례·장 제목·번호 단계·본문·표·그림·머리말·쪽 번호를 자동으로 찾아 보여 줍니다.
   저장해 둔 양식이 있으면 **양식 저장소**에서 누르기만 하면 됩니다. 자주 쓸 양식은 1단계 오른쪽 위 [+ 양식 저장]으로 보관합니다.
   양식이 **여러 파일로 나뉘어 있으면**(앞표지·목차·본문 스타일·표 그림 양식 등) 한꺼번에 올리세요(아래 '여러 파일 양식').
2. **어떤 문서를 이 양식에 맞게 바꿔드릴까요?** — 바꿀 문서(.docx 또는 .hwpx)를 올립니다.
3. 설정 창에서 답합니다.
   - 1-1 제목(표지)을 만들까요? → 1-2 직접 작성 / 본문 내용 분석 후 자동 생성
   - 2 목록(차례)을 만들까요?
   - 3 페이지 번호: 제목부터 1 / 본문부터 1 / 필요 없음 / 별도 지정(본문 첫 쪽 번호)
   - 4-1 머리말을 만들까요? → 4-2 직접 작성 / 본문 내용 분석 후 자동 생성 / 양식에 있는 머리말 그대로 작성
     ('양식 그대로'는 양식 머리말을 쪽 종류(모든 쪽·짝수 쪽·홀수 쪽)마다 그대로 쓰고, 장 제목 자리('제7장 …')만
     문서의 장 제목으로 바꿉니다. 문서에 '제N장'이 없으면 장 제목 자리도 양식 글자 그대로 둡니다.)
   - 5 큰 표가 쪽을 넘어가면 어떻게 나눌까요? → 쪽 경계에서 나눔 / 셀 단위로 나눔
     (한 쪽을 넘는 표가 있을 때만 묻습니다. 어느 쪽이든 표가 쪽 아래로 넘치지 않고, 표 머리행은 다음 쪽에도 나옵니다.
     한 쪽 안에 드는 표는 양식대로 두어 쪽 끝에 걸리면 통째로 다음 쪽으로 넘어갑니다.)
4. [변환하기]를 누르면 결과 파일이 **다운로드 폴더**에 저장됩니다. 같은 양식으로 다른 문서도 이어서 바꿀 수 있습니다.

내 컴퓨터에서 쓰려면 이 저장소를 내려받아 `web/index.html`을 브라우저(크롬·엣지·웨일)로 열면 됩니다.
처음 열 때 변환 엔진(약 10 MB)을 인터넷에서 한 번 받아 옵니다.

## Google 드라이브에서 가져오기

[파일 가져오기] → [Google 드라이브에서 가져오기]를 누르면 Google 로그인 후 파일 고르기 창이 뜹니다.
- 권한은 `drive.file` 하나뿐이라, **사용자가 그 창에서 고른 파일만** 읽을 수 있습니다. 드라이브의 다른 파일은 보지 못합니다.
- 고른 파일은 이 브라우저로 내려받아 처리하며, 결과도 다운로드 폴더에 저장됩니다(드라이브에 쓰지 않음).
- 구글 문서(Google Docs)로 저장된 글은 워드(.docx)로 내보내 받아 '바꿀 문서'로 쓸 수 있습니다.
- 사이트 주소(https)로 열었을 때만 쓸 수 있습니다. `web/index.html`을 파일로 직접 열면 이 버튼은 꺼집니다.

## 여러 파일 양식

회사 양식이 앞표지·목차·본문 스타일·표 그림 양식처럼 파일 여러 개로 나뉘어 있으면, 1단계에서 **한꺼번에** 올립니다.
한꺼번에 끌어다 놓거나, [파일 가져오기]에서 여러 개를 고르거나, Google 드라이브에서 여러 개를 고르면 됩니다.
올린 뒤에도 카드의 **[+ 파일 더하기]**로 파일을 더 넣을 수 있습니다. 부분마다 알맞은 파일을 골라 하나의 양식으로 씁니다.

| 부분 | 고르는 파일 |
|---|---|
| 본문(본문·제목 단계·빈 줄, 쪽 설정·글꼴의 바탕) | 본문 문단이 있고 제목 단계가 가장 많은 파일 |
| 표·그림·장 제목·머리말·쪽 번호 | 표·그림 예시와 진짜 '제N장' 장 제목이 든 파일(같으면 본문 파일) |
| 표지·차례 | 그 부분만 든 파일 → 본문 파일 안의 것 → 다른 파일 안의 것 |

- 카드에 파일마다 맡은 부분이 표시됩니다. 쓰이지 않은 파일은 '안 씀'으로 나옵니다.
- [+ 양식 저장]을 누르면 묶음 하나로 저장됩니다(예: '본문 스타일 외 3개'). 같은 파일들을 순서만 바꿔 올려도 같은 양식으로 알아봅니다.

## 양식 저장소

- 1단계에서 양식을 올린 뒤 오른쪽 위 **[+ 양식 저장]**을 누르면 양식이 양식 저장소에 번호와 함께 들어갑니다.
  저장소는 넓은 화면에서는 왼쪽, 좁은 화면에서는 1단계 위에 있습니다.
- 다음에는 저장소에서 양식을 누르기만 하면 1단계가 끝납니다. 누를 때마다 양식을 다시 분석하므로, 변환 엔진이 나아지면 새 판으로 분석됩니다.
- 연필 아이콘으로 이름을 바꾸고(Enter 저장, Esc 취소), 휴지통 아이콘으로 지웁니다. 지우기 전에는 한 번 묻습니다.
- 이미 저장한 양식 파일을 다시 올리면 단추가 '✓ 저장됨'으로 바뀝니다. 파일 이름이 아니라 내용으로 알아봅니다.
- **보관 위치**: 이 컴퓨터의 이 브라우저 저장 공간(IndexedDB)입니다. 어디로도 전송되지 않습니다. 그래서:
  - 다른 컴퓨터나 다른 브라우저에서는 보이지 않습니다.
  - 브라우저의 '쿠키 및 기타 사이트 데이터'를 지우거나 시크릿·InPrivate 창을 닫으면 함께 지워집니다.
  - 사파리는 이 사이트를 7일 넘게 쓰지 않으면 지울 수 있습니다.

  원본 양식 파일은 따로 보관해 두세요.

## 양식의 표·그림 제목

양식마다 표·그림 제목을 다는 방식이 달라 둘 다 알아봅니다.

| 양식 | 결과 |
|---|---|
| 제목이 표·그림에 붙은 **캡션** | 표·그림에 양식 캡션을 답니다 |
| 제목이 표 위·그림 아래에 **따로 놓인 문단**(예: 스타일 '<표> 개요 6'의 '<표 7-1> 표제목') | 같은 자리에 양식 제목 문단을 따로 둡니다. 제목과 표·그림은 같은 쪽에 오고, 표 바로 밑에 다음 표 제목이 붙지 않게 빈 줄을 하나 둡니다 |
| 제목 모양이 없음 | 문서의 제목을 문서 모양·번호 그대로 둡니다 |

- 번호는 양식의 자동 번호를 씁니다(문서에 직접 친 '<표 3>' 같은 번호는 지우고, 다르면 알림으로 알려 줍니다).
- 제목 끝에 **'(계속)'**이 붙은 표·그림(한 표를 여러 쪽으로 나눠 친 것)은 앞과 **같은 번호**를 글자로 넣고 번호를 늘리지 않습니다.
  양식에 '(계속)' 제목 모양(예: '<표 7-2(계속)>')이 있으면 그 모양을 씁니다.

## 문서의 제목 번호

문서의 제목은 양식의 제목 단계(예: `1.` → `(1)` → `1)` → `①`)에 차례로 맞추고, 번호는 양식의 자동 번호로 깔끔하게 바꿉니다.

- 한글의 개요·문단 번호로 단 제목은 그 단계대로 맞춥니다.
- 번호를 글자로 친 제목(`1.`·`(1)`·`1)`·`가.`·`①`·`Ⅰ.`·`제1절`·`○` 등)은 짧고 문장이 아닌 줄만 제목으로 보고, 번호 모양이 처음 나온 순서대로 단계를 정합니다.
- **여러 단 번호**(`2-1)`·`1-7.`·`1.1`·`1.1.1`·`Ⅱ-1.`)는 윗제목 바로 아래 단계입니다. 예를 들어 `2)` 아래 `2-1)`이면 `2)`보다 한 단계 아래 제목이 됩니다.
  결과에는 양식 번호만 남습니다. `2-1) 조사 결과` 같은 제목은 그 단계의 양식 번호(예: `1)`)가 붙습니다.
  - 한글 개요 번호 제목 아래에 글자로 친 `2-1)`도, 윗제목 번호(2)가 맞으면 그 아래 단계 제목이 됩니다.
  - `)`·`.`로 끝나지 않는 `1.1`·`10-20`은 숫자 범위·소수일 수도 있습니다. 그래서 윗제목 번호와 맞을 때만 제목으로 봅니다(`3.` 아래 `3.2`).
    윗단 번호 모양이 문서에 없으면 두 번 넘게 나와야 제목으로 봅니다.
- 문서를 올리면 2단계 칸에 어떻게 맞췄는지 보여 줍니다(예: `'1-7.' → '1.', '1)' → '(1)', '2-1)' → '1)'`).
  친 번호와 결과 번호가 다르면(예: `1-7.` → `1.`) 완성 화면 알림으로 알려 줍니다.

## 차례의 쪽 번호

쪽 나눔은 한글 프로그램이 계산합니다. 그래서 차례의 쪽 번호 자리에 한글의 **상호 참조(쪽 번호)** 를 넣어 둡니다.

- 결과 파일을 **한글에서 열면 한글이 제목·표·그림이 있는 쪽을 계산해 차례에 채웁니다.** 한글에서 고쳐 쪽이 바뀌어도 다시 열면 맞게 바뀝니다.
- 가리키는 대상은 개요 번호 제목 문단과 표·그림(틀)입니다. 개요 번호가 없는 제목처럼 가리킬 수 없는 항목은 쪽 번호를 비워 두고, 완성 화면에서 몇 개인지 알려 줍니다.
- 한글 2020으로 확인했습니다. 시험 문서 11개의 차례 항목 430개가 PDF의 실제 쪽과 모두 같았습니다.
- 한글이 아닌 프로그램(뷰어 등)은 이 값을 다시 계산하지 않아 빈칸으로 보일 수 있습니다.

## 문제가 생기면

- 변환이 멈추면 화면에 **무엇을 하다가**, **문서의 어디서**(몇 번째 문단·어떤 표), **왜** 그런지와 **이렇게 해 보세요**가 나옵니다.
  설정을 바꿔 그 단계를 건너뛰는 방법(예: 차례 '아니오')도 함께 알려 줍니다.
- 표·그림 하나를 양식 모양으로 바꾸지 못하면 변환을 멈추지 않고 **그 표·그림만 문서 모양 그대로** 두고 결과 화면에 알립니다(글자는 그대로).
- 안내의 **[오류 정보 복사]**로 복사한 내용을 알려 주시면 어디를 고칠지 바로 찾을 수 있습니다.

## 아직 안 되는 것 (다음 판)

- .hwp 파일 직접 읽기, 워드(.docx) 양식.
- 문단 안 일부만 굵게·밑줄(원고 색 글자는 살립니다).

## 어떻게 동작하나

```
web/            화면(index.html, app.js, style.css)과 엔진 묶음(engine_bundle.js — tools/build_web.py가 만듦)
engine/         변환 엔진(파이썬, lxml) — 브라우저 안 Pyodide와 일반 파이썬에서 똑같이 돈다
  template_profile.py  양식 자동 분석: 쪽을 나눠 표지·차례·본문을 찾고 역할별 기준 문단을 고른다
  format_transfer.py   서식 옮기기: 원고 문단마다 역할을 정하고 양식 문단을 복사해 원고 글자를 채운다
  table_fit.py         표가 쪽을 넘지 않게: 셀 글자로 표 높이를 어림(한글이 저장한 줄 배치 정보로 맞춘 값)하고,
                       한 쪽을 넘는 표만 '글자처럼 취급'을 끄고 쪽 경계에서 나뉘게 한다
  docx_hwpx.py         워드 문서 → 한글(HWPX) 원고
  service.py           양식 분석 → 문서 살펴보기(규칙으로 못 정한 문단 자동 판단) → 설문 답으로 변환
tests/          시험 도구(아래)
tools/          build_web.py
```

HWPX는 ZIP 안의 XML이라 한글 프로그램 없이 만들 수 있습니다. 규칙: XML은 lxml로만 고치고, 내용을 바꾼 문단의 줄 배치 정보(linesegarray)는 지우며,
압축할 때 `mimetype`을 첫 항목·비압축으로 넣습니다. 결과마다 패키지·글자 보존·서식 일치·쪽을 넘을 수 있는 표를 자동 검사합니다(검증보고).
한글이 있는 PC에서는 PDF로도 확인합니다(본문 영역 아래로 넘친 글자가 없는지 등).

## 개발

```
python tools/build_web.py                                   # 엔진을 고친 뒤 웹 묶음 다시 만들기
python -X utf8 engine/service.py 양식.hwpx 문서.docx 작업폴더 '{"표지":{"만들기":true},"차례":{"만들기":true},"쪽번호":{"방식":"본문부터"},"머리말":{"만들기":true,"방식":"양식"}}'
node tests/pyodide_node_test.mjs <node_modules/pyodide> 양식.hwpx 문서.hwpx 결과폴더   # 브라우저와 같은 Pyodide 환경
python -X utf8 tests/e2e_web.py 양식.hwpx 문서.hwpx 결과폴더 [--file]                # 실제 브라우저(Edge)로 화면 끝까지
python -X utf8 tests/e2e_vault.py 양식A.hwpx 양식B.hwpx 문서.hwpx 결과폴더 [--file]  # 양식 저장소(저장·새로 고침·고르기·이름·지우기·다른 창)
python -X utf8 tests/e2e_multi.py 앞표지 목차 본문스타일 표그림양식 문서 결과폴더 [--file] # 여러 파일 양식(한꺼번에·저장·순서·파일 더하기)
python -X utf8 engine/service.py "앞표지.hwpx|목차.hwpx|본문.hwpx" 문서.hwpx 작업폴더       # 명령줄에서 여러 파일 양식은 '|'로 잇는다
python -X utf8 tests/try_template.py 양식.hwpx 원고설정.json 작업폴더 [--pdf]          # 한글이 있는 PC: PDF까지 확인
```

필요한 것: 파이썬 3.10+, lxml (웹에서는 Pyodide 0.29.5가 대신함).
